# 라우팅 — 언제 무엇을 붙일까

이 파일은 **"이 신호가 오면 저 자원을 붙여라"** 만 적는 곳입니다.
자원(내용)은 자기가 언제 쓰이는지 모릅니다. 그래서 문서를 쪼개도, 카드 하나가 문서 여섯 개를
가리켜도 그냥 됩니다.

`.axiom/knowledge/_index.md` 에 키워드를 적는 것과 **같은 방식**입니다 — 정규식이 아니라 단어 목록입니다.

## 쓰는 법

위쪽 `---` 블록의 `routes:` 아래에 적습니다. 계약카드 몇 장의 **요청 문장 조건**이 이미 들어 있습니다.

```yaml
---
axiomSchema: 1
routes:
  # 요청 문장이나 코드 중 하나만 걸려도 붙습니다 (OR)
  - attach: badge-component
    when:
      code: ["<Badge", "BadgeProps"]     # 지금 열린 파일에 이 말이 있으면
      ask: [뱃지, 배지, badge, 상태칩]    # 요청 문장에 이 말이 있으면

  # 군마다 하나씩 다 있어야 붙습니다 (AND) — "버튼"이면서 "추가"일 때만
  - attach: button-component
    when:
      ask_all:
        - [버튼, button]
        - [넣, 추가, 만들, 바꿔, 교체]
---
```

| 조건 | 뜻 |
| --- | --- |
| `code` | 현재 파일·의존 코드에 이 말이 있으면 |
| `ask` | 요청 문장에 이 말이 있으면 |
| `ask_all` | 요청 문장에 **각 묶음마다 하나씩** 다 있으면 |

`code`와 `ask`는 서로 OR입니다(둘 중 하나만 걸려도 붙음). 대소문자는 가리지 않습니다.
