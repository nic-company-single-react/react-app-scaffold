# PoC(Proof of Concept)를 위한 준비


## 장비 준비
* MAC mini 48gb
* 노트북
* USB-C 이더넷 어댑터(노트북에 이더넷 포트 없을 때)
* 랜 케이블


## 네트워크 구성
* 노트북과 MAC mini를 랜 케이블로 직결 - 공유기도, 사내망도 거치지 않는 폐쇄망 구성. (폐쇄망 설득력)
* 양쪽 고정IP
* 노트북의 Wi-Fi는 끈 상태로, 화면에 Wi-Fi 아이콘이 보이게 배치.
* MAC mini는 Wi-Fi 끄고 이더넷만 활성. (시연 중 절전 상태로 들어가면 안되므로 시스템 설정에서 잠자기를 끈다.)


## MAC mini 구성, 설정
* 다음 사항을 먼저 설정한다.
	- 시스템 설정 → 일반 → 공유에서 원격 로그인(SSH)과 화면 공유 켜기
	- 에너지 절약: 잠자기 끄기. 시연 중 절전 들어가면 첫 요청만 유독 느려집니다
	- 자동 로그인 켜기 (재부팅 후 사람 없이 서비스가 뜨려면 필요)
	- 정전 후 자동 시작 켜기
	- 고정 IP 할당
* 추론엔진실행 : Ollama
* 모델 : 1순위(qwen3-coder:30b-a3b-q8_0), 2순위(qwen3.6:27b), 3순위(glm-4.7-flash, qwen3.8:27b)


## 장비 반입이 안될경우를 대비해서 준비할 사항
* 폐쇄망에서 고객 노트북으로 브라우저를 통해 접속하여 시연하는 방법
	- 시연 가능 페이지를 만들어 브라우저로 시연.
	- 시연용 계정으로 로그인하여 시연.
* 녹화 영상으로 대체
* 인쇄물로 대체
	- 시나리오 진행 스크린샷 추가
	- 1장 요약본 등

### 시연용 사이트 생성 준비
* 시연용, 자료용 두가지 종류로 나눌 수 있음.
	- 시연용 - Axiom이 실제로 도는 걸 보여주는 것.
	- 자료용 - 소개, 영상, 문서, 1장 요약을 모아둔 정적 페이지.
* 시연용 code-server 준비 순서
	- code-server에서 Axiom 동작 확인 (반나절) — 여기서 갈립니다
	- 시연용 프로젝트·계정 구성 (반나절)
	- Cloudflare Tunnel + 도메인 연결 (반나절)
	- 노트북이 아닌 외부 회선에서 접속 테스트 (테더링으로 확인) — 사내에서만 테스트하면 의미 없습니다
	- 리셋 스크립트를 웹에서도 돌 수 있게 (반나절)
* 원격 사이트의 진짜 가치는 방문 시연보다 오히려 원격 미팅이나 사후 추가 검토 쪽에 있습니다 — "직접 만져보시겠습니까"를 열어줄 때 유용.
